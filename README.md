# londonwanted.com

A wanted poster website for London, Ontario, styled after the London Police Service.

## Features

✨ **Multi-page Website**
- Home page with hero section and public safety information
- Wanted Persons database with detailed poster cards
- Tip submission form with multiple reporting channels
- About page with FAQs

🎨 **Professional Police-Themed Design**
- Blue and gold color scheme inspired by law enforcement
- Authentic wanted poster styling
- Responsive design for all devices
- Clean, professional navigation

📋 **Content Pages**
1. **Home (index.html)** - Welcome page with overview
2. **Wanted Persons (wanted.html)** - Gallery of wanted person posters
3. **Report a Tip (contact.html)** - Form to submit tips and contact information
4. **About Us (about.html)** - Program information and FAQs

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Navigate through the pages using the menu

## Customization

### Add More Wanted Persons
Edit `wanted.html` and duplicate the `.wanted-poster` div, updating:
- Name, age, and physical description
- Charges and last seen location
- Any relevant aliases or warnings

### Change Colors
Edit `styles.css` and modify:
- Primary blue: `#003d7a`
- Secondary blue: `#0066cc`
- Accent yellow: `#ffcc00`
- Danger red: `#cc0000`
